================================================================================
WORKFLOW CONFIGURATION
================================================================================

Trigger Type: Manual Dispatch (No Schedule)
  → You control when it runs
  → Perfect for testing and production use

Inputs:
  • max_pages: Pages per run (default: 50)
    Options: 10, 25, 50, 100, 200
    Recommendation: 100 for initial crawl

  • max_depth: Link depth to follow (default: 2)
    Options: 1, 2, 3
    Recommendation: 2 (balance between coverage and time)

  • runs_left: Chain runs if URLs pending (default: 5)
    Options: 0-20
    Explanation: If URLs remain after this run, automatically queue another run
    Recommendation: 5 (will auto-chain up to 5 more runs)

Environment Variables:
  • DATABASE_URL: Your Layerbase PostgreSQL connection

Runner: ubuntu-latest
Python: 3.11
Dependencies: beautifulsoup4, lxml, psycopg[binary], feedparser
